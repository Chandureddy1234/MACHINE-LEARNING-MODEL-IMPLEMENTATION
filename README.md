Spam Email Detection using Machine Learning

This project focuses on building a predictive machine learning model to classify emails as Spam or Not Spam using Natural Language Processing techniques. The objective was to demonstrate end-to-end ML workflow including data preprocessing, model training, evaluation, and real-world testing.

🔧 Project Implementation

The model was developed using Python in Jupyter Notebook, utilizing:

pandas – data handling
scikit-learn – machine learning models and evaluation
TfidfVectorizer – text feature extraction
matplotlib & seaborn – data visualization

The dataset was loaded directly from a public source and processed to extract meaningful features from textual data.

⚙️ Working Pipeline
Raw Text Data → Text Cleaning → TF-IDF Vectorization → Train/Test Split → Model Training → Evaluation → Prediction

The model converts text into numerical vectors using TF-IDF, enabling machine learning algorithms to understand textual patterns.

🤖 Model & Evaluation

Multiple models were explored, with Multinomial Naive Bayes performing effectively for text classification.

Evaluation metrics used:

Accuracy Score
Confusion Matrix
Classification Report

The model achieved high accuracy and demonstrated strong capability in identifying traditional spam patterns such as phishing and promotional messages.

🧪 Real-World Testing

The model was tested on modern scenarios including:

Phishing attacks (bank alerts)
Promotional scams (gift cards)
Crypto investment scams
Normal conversations and business emails

Results showed:
Accurate detection of traditional spam
Some limitations with modern scam patterns (e.g., crypto-related messages), highlighting dataset dependency
